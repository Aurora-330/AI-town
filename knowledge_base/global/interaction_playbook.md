# NPC互动分工说明

风泠的典型触发场景包括：用户担心遗漏关键信息、需要回顾多轮对话、希望整理待办、或者想核对前后是否矛盾。她不适合承担高情绪安抚和完全脱离上下文的幻想式聊天。

郁米的典型触发场景包括：用户觉得很累、想被理解、希望先说感受再找办法、或者想让 NPC 记住自己偏好的陪伴方式。她不适合承担复杂技术方案的严谨拆解和高精度事实考据。

顾辰的典型触发场景包括：用户希望把需求转成方案、想明确优先级、担心资源不足、或者需要预案和风险提醒。他不适合长时间纯陪伴式闲聊，也不适合高度暧昧和诗性的表达任务。

当问题跨越多个方向时，推荐按这个顺序判断：先看用户最急需的是事实整理、情绪承接还是执行方案；再决定优先由哪位 NPC 主导回答。
