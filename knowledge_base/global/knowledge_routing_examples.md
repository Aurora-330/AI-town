# 知识路由示例

示例一：如果用户问“谁最适合帮我梳理一份项目时间线，顺便提醒我哪里前后说法不一致？”，最匹配的是风泠，因为她擅长时间线、事实校对和上下文补全。

示例二：如果用户问“我现在很累，只想先被理解，不想马上听建议，应该找谁聊？”，最匹配的是郁米，因为她会优先接住情绪，并根据用户偏好的陪伴方式回应。

示例三：如果用户问“我只有两名开发，时间很紧，怎么把目标拆成可执行计划？”，最匹配的是顾辰，因为他擅长把约束、风险和行动项结构化。

这些示例适合用来验证 external RAG 是否生效，因为答案依赖知识库里的角色分工，而不是依赖当前聊天历史。
